# DKCR PopTracker (v0.3.0)
This is the PopTracker package designed to work with the ***Donkey Kong Country Returns*** [**AP World v0.1.0-beta**](https://github.com/CallmeZewo/DKCR_APWorld/releases), built for either manual tracking or automatic tracking through Archipelago. The logic in this pack is based on the original 2010 release of the game on the Nintendo Wii, so if used for any other version of the game, it may have logic inaccuracies. This version of the pack was built for the v0.35.3 release (or later) of PopTracker, so it may have issues on earlier versions. You can install the PopTracker program [here](https://github.com/black-sliver/PopTracker/releases/latest).

### Installation
Download the zip folder from the [latest release](https://github.com/MagicMason1000/DKCR-AP-PopTracker-Package/releases) (named "dkcr\_ap\_tracker\_v0.3.0") and place it in the "packs" folder of your PopTracker installation. It may be either a zipped or unzipped folder, but make sure there aren't two layers of folders to get to the core files. If you have any issues, ping @magicmason1000 in the Archipelago Discord server.

### Important Notes!
* A list of known bugs with this pack can be found on the [AP World Google Doc](https://docs.google.com/document/d/1HLGthO0-K62RDuJ4j3v3pbDkw2cnlp-bfqjszAG5CSQ/edit?usp=sharing). If you encounter a bug not listed on that document, please report it in the [Archipelago Discord server](https://discord.com/channels/731205301247803413/1258198433152499743)!
  * The Google Doc mentioned above also has a guide for all the locations in the game, so reference it if you need further help with playing your game!
* The AP World is still in development, so the Abilities, Vehicles, and Shop Items on the item tracker are only static images for the meantime. The Rare Orbs and Golden Temple also have no functionality. These are all planned to be added in later releases!
