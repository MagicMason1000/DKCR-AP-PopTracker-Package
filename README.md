# DKCR PopTracker (v0.2.3)

This is the PopTracker package designed to work with the ***Donkey Kong Country Returns*** [**AP World v0.0.4**](https://github.com/CallmeZewo/DKCR_APWorld), built for either manual tracking or automatic tracking through Archipelago. The logic in this pack is based on the original 2010 release of the game on the Nintendo Wii, so if used for any other version of the game, it may have logic inaccuracies. This version of the pack was built for the v0.35.3 release (or later) of PopTracker, so it may have issues on earlier versions. You can install the PopTracker program [here](https://github.com/black-sliver/PopTracker/releases/latest).



### Installation

Download and place the folder containing all of the pack files (named "dkcr\_ap\_tracker\_v0.2.3") into the "packs" folder of your PopTracker installation. It may be either a zipped or unzipped folder, but make sure there aren't two layers of folders to get to the core files. If you have any issues, ping @magicmason1000 in the Archipelago Discord server.



### Important Notes!

* As the AP World is still in early development, this pack does not have much item functionality yet. Most of the items on the list are all static images, but as more is added into the AP World, their functionality will be added in on the tracker. Currently, the only trackable items are Puzzle Pieces, KONG Letters, and Map Keys.

  * Map Keys must be tracked manually. The AP World currently doesn't handle the keys, so auto-tracking is not yet possible for them. There are plans to have this implemented in upcoming versions!
* Keep in mind that in-game, you do not actually receive any items yet as there is no ROM patching. This tracker only tells you what you have on the server's side. This means that for both Boss and K levels, you might be able to enter these levels in-game, but according to logic you shouldn't be able to. For K levels, you must have been sent all of the KONG Letters for the world; for Boss levels, you must meet its Puzzle Piece requirement which should be set in your YAML. To stay within logic, only go for checks that are listed as accessible (green) on the tracker, even if your game says you can access the others!
